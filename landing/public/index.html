The Problem

Why Tamil Students Have No AI Tools

Sri Lanka ranks 4th most climate-affected country globally. Tamil students face a double crisis — recurring natural disasters and a complete absence of accessible AI learning tools.

🌊
Climate Disasters Close Schools பருவநிலை பேரிடர்
In late 2025, Cyclone Ditwah damaged 1,382 schools and disrupted education for over 550,000 children in the Central and Uva provinces. Students lost school bags, books, and stationery in the floods. By January 2026, many schools were still recovering.
📡
No Internet Access இணையதள வசதி இல்லை
Rural and estate areas in Sri Lanka have little or no internet connectivity. Every existing Tamil AI app requires internet, a paid account, or collects data through a free tier that moves to a paid model later.
💸
Cannot Afford Tutoring தனியார் கல்வி கட்டணம்
Household incomes in estate Tamil communities average Rs 30,000/month (~$95 USD). Private tutoring, subscriptions, and even mobile data costs are out of reach for most families.
📄
Textbooks Invisible to Software மரபு எழுத்துரு பிரச்சனை
Sri Lankan Tamil government textbooks use legacy encoding fonts (Baamini, SHREE-TAM7, FMAbhaya). PyMuPDF, PDFBox, pdfplumber — every standard extractor returns zero readable text from these books.
The Solution

Everything a Student Needs — Offline

Nunarivu AI runs entirely on the device. Once set up, it works in a village with no electricity infrastructure, during a cyclone, with the phone in airplane mode.

🤖
On-Device Gemma 4 E2B
சாதன AI மாதிரி
Runs Google Gemma 4 E2B via LiteRT-LM directly on the Adreno GPU. No API calls, no cloud, no data ever leaves the phone. Streams tokens in real time.
🔍
Tesseract OCR Pipeline
Tamil OCR தொழில்நுட்பம்
The only solution that reads legacy-font Tamil PDFs. Pages rendered at 2× scale → Tesseract (tam+eng, LSTM, PSM 6) → Tamil Unicode text. Cached permanently in SQLite — processed once, instant forever.
🎤
Tamil Voice Q&A
குரல் கேள்வி பதில்
Tap the mic and ask in spoken Tamil or English. Uses Android's built-in ta-IN offline speech recognition — no internet needed. Waits patiently with 6-second silence tolerance.
🔊
Text-to-Speech Answers
பதில்களை படிக்கும்
Every AI answer read aloud with one tap. Critical for students with reading difficulties or low literacy. Offline via Android's built-in TTS engine.
📚
161 Tamil Textbooks
161 தமிழ் பாடநூல்கள்
Full Grade 10 and Grade 11 Sri Lankan Tamil curriculum — Maths, Science, History, Tamil Literature, Islam, Christianity, Hinduism, Geography, ICT, Health, Commerce and more. Auto-organised by grade and subject.
🛡️
Zero Hallucination Design
தவறான தகவல் இல்லை
The model answers only from the current textbook page. Hard block on outside knowledge — if the answer is not on that page, the app says so in Tamil. Safe for exam preparation.
👤
Multi-Student Profiles
பல மாணவர் சுயவிவரங்கள்
Multiple students share one phone — siblings, classmates. Each profile has separate chat history, grade filter, language preference, learning disability mode, and AI persona.
⏰
Study Reminders & Badges
நினைவூட்டல் மற்றும் பதக்கங்கள்
Daily study alarms with Tamil notifications — "படிக்க நேரம்! / Time to Study!" Achievement badges unlock by question count and study-day streaks. All tracked locally.
Technical Pipeline

How It Works

Every step runs locally on the device. No network calls, no external APIs, no telemetry.

1
PDF Page → High-Resolution Image
Android's native PdfRenderer renders each page at 2× scale (1044×1368 px) as a 32-bit PNG. White background for clean OCR contrast. Temp copy to ASCII path avoids Tamil filename bugs.
2
Tesseract OCR → Tamil Unicode Text
Tesseract 4 LSTM engine extracts Tamil + English text from the image. Result cached permanently in SQLite with chunk_index = −1.
lang: 'tam+eng' · oem: 3 (LSTM) · psm: 6 (uniform block)
3
Student Asks a Question
Tap the mic → Android ta-IN offline STT → Tamil text. Or type in Tamil/English. The current page number is tracked by the PDF viewer.
4
Strict Page-Grounded Prompt → Gemma 4
The OCR text and question are assembled into a strict prompt that forbids outside knowledge. If the answer isn't on the page, Gemma 4 says so in Tamil.
Answer STRICTLY using ONLY the page text below. Do NOT use any outside knowledge.
5
LiteRT-LM Streams Tokens via JNI
A custom Kotlin InferencePlugin bridges Gemma 4 via LiteRT-LM C++ to Flutter's EventChannel. Tokens stream in real time to the UI. Adreno 710 GPU with automatic CPU fallback.
EventChannel("com.nunarivu/stream") → Stream<String> tokens
6
Answer Read Aloud in Tamil
Streaming answer displayed word-by-word and simultaneously read aloud via flutter_tts. One-tap "In English" or "தமிழில்" buttons re-explain in the other language.

Get Started

Install in 3 Steps

Works on any Android phone running Android 7.0 or newer. ~3 GB storage needed for the AI model.

1
Install the APK
Download and install the app on any Android phone. Enable "Install from unknown sources" in Settings if needed.
📥 Download APK
2
Download the AI Model
Download Gemma 4 E2B from HuggingFace (free, ~2.4 GB). Copy the .litertlm file to your phone.
Android/data/com.example.nunarivu_ai/files/models/
3
Turn on Airplane Mode & Ask
Open the app → create a student profile → ask a question in Tamil. Turn on Airplane Mode — everything still works. ✅
📖 Full Setup Guide on GitHub
🔒
Zero data leaves your device. Ever.
No analytics. No telemetry. No user account. No server calls. All chat history, student profiles, OCR text, and usage data is stored exclusively in local SQLite on the student's phone. Not even crash reports are sent anywhere.
